# Tesla сервис — набор для диагностики

Программа читает данные с CAN-шины Tesla Model 3 / Y и делает понятный отчёт для клиента:
состояние батареи, деградация, напряжение каждой ячейки, 12V аккумулятор, пробег, активные предупреждения.
**Только чтение**: машина ничего не получает от программы.

## 1. Что купить
| Что | Зачем | Примерно |
|---|---|---|
| **CAN-адаптер**: PCAN-USB (Peak) — надёжнее всего, или CANable 2.0 — дешевле | связь ноутбука с машиной | $40–300 |
| **Кабель-переходник к диагностическому разъёму Tesla** под конкретную модель и год | подключение адаптера к машине | $30–80 |
| Переходник USB → Ethernet (если в ноутбуке нет порта) | для Toolbox / Ethernet-диагностики | $15 |
| Подписка Tesla Toolbox 3 (сначала на месяц) | калибровки, прописка блоков | $150/мес |
| Мультиметр, HV-перчатки класса 0, тестер изоляции | ремонт, безопасность | $150+ |

Кабель у разных лет Model 3/Y разный: продавцу называйте модель и год машины.
Bluetooth-адаптеры типа OBDLink — для телефонного приложения Scan My Tesla, этой программой не поддерживаются.

## 2. Установка на Windows-ноутбук
1. Скопировать эту папку на ноутбук (флешка / Google Drive), например в `C:\tesla-service`.
2. Поставить драйвер адаптера:
   - PCAN-USB — «PEAK-System Driver Package» с сайта peak-system.com;
   - CANable — драйвер обычно не нужен, адаптер появляется как COM-порт (номер смотреть в «Диспетчере устройств»).
3. Открыть PowerShell в папке и запустить:
   ```
   powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1
   ```
   Скрипт поставит Python, библиотеки, Claude Code и сделает тестовый отчёт.
4. В этой папке запустить `claude` — он прочитает `CLAUDE.md` и будет в курсе всего.

## 3. Программа с кнопками
- **start.bat** — двойной щелчок, программа откроется в браузере.
- **start.command** — то же для Mac (двойной щелчок в Finder).
- **start-phone.bat** (для телефона) — то же, плюс в окне будет адрес для телефона (телефон и ноутбук в одной Wi-Fi сети). Только в своей сети: пароля нет.
- В «⚙ Настройки» выбрать адаптер (сначала стоит «Симуляция» — можно потренироваться без машины), название сервиса, телефон.
- Заполнить клиента и VIN, нажать услугу:
  - **синие** — программа сама снимает данные и делает отчёт;
  - **фиолетовые** — чек-лист по шагам, данные «до» и «после», в акте видно, какие ошибки ушли;
  - **серые** — работа партнёра, программа только записывает заказ.
- «Завершить и сделать акт» — акт для клиента (печать в PDF из браузера). История заказов — слева.

## 4. Работа из командной строки
```
.\.venv\Scripts\python tesla.py listen --interface pcan --channel PCAN_USBBUS1 --minutes 3
.\.venv\Scripts\python tesla.py listen --interface slcan --channel COM3 --minutes 3      # для CANable
.\.venv\Scripts\python tesla.py report logs\<файл>.asc --car "Model 3 2019, VIN ..., клиент Гио"
```
- Машина должна быть проснувшейся (открыть дверь / включить экран).
- Отчёт для клиента — `reports\<файл>.html`, открывается в браузере, можно распечатать в PDF.
- Проще всего сказать Claude: «сними данные с машины и сделай отчёт» — он сам запустит команды и объяснит результат.

## 5. Проверка без машины
```
.\.venv\Scripts\python tesla.py simulate
.\.venv\Scripts\python tesla.py report logs\simulated.asc --car "Тест"
```
